Bookmarks for mdterm

ma sets a mark, 'a jumps back. Marks persist per file across sessions. Plan only, nothing implemented yet.

Decisions

decidedMouse capture -> M

This frees m for marks.

decideda-z per file

No global A-Z marks. Uppercase after m or ' cancels, like any other key.

decidedLetters in the margin

The letter replaces the left border glyph on marked rows. See section 4.

What the code does today

conflictm is taken

m toggles mouse capture (viewer.rs:1647, help :3637). ' and M are free.

trapoffset is not stable

Position is an index into wrapped. It changes on resize, -w, line numbers, image rows and edits. Storing it raw puts you on the wrong line next session.

traphelp eats keys

is_help_toggle runs before handle_normal, so mh would open help. Pending keys have to be checked first.

reusesource ranges exist

parser.into_offset_iter() (markdown.rs:1585) already gives byte ranges. Line just doesn't keep them.

reuseback stack exists

nav_history + Backspace already does "go back". Jumping to a mark pushes onto it.

1. Anchors that don't depend on width

Add source: usize to Line. It holds the byte offset of the source block that produced the line. It gets stamped in render_with's event loop: after each process(event, range), the lines just pushed get range.start. wrap_lines copies it onto every wrapped piece. Renderer internals stay the same.

markdown->pulldown events + range->Line { source }->wrap_lines keeps source->anchor_at / resolve 
#[derive(Serialize, Deserialize, Clone)]
pub struct Anchor {
    pub line: usize,  // 1-based source line of the block start
    pub row: usize,   // wrapped row within that block
    pub text: String, // trimmed source line (max 80 chars), used to re-anchor
}
FunctionBehavior
anchor_at(wrapped, offset, src)Reads wrapped[offset].source, converts it to a line number, and counts rows back to the first wrapped line of that block.
resolve(anchor, wrapped, src)If the line still matches text, use it. If not, find the nearest line with the same text (the file was edited). If there is none, clamp line. Then map to the block's first wrapped line, add row (clamped to the block's rows), and clamp to max_offset.

Marks are resolved when you jump, so resize and live reload need no extra code.

2. New module src/marks.rs

All mark logic and persistence lives here. viewer.rs only handles the keys.

Location

dirs::state_dir() (Linux ~/.local/state/mdterm/marks.json), falling back to data_dir() (macOS ~/Library/Application Support/mdterm/). Marks are state, not config, so they don't go next to config.toml.

Key

fs::canonicalize(path), so ./a.md and ../repo/a.md share marks.

Writes

Saved right away on m, not on exit, so a crash doesn't lose them. Read-modify-write, then tmp + rename for an atomic write. Two instances can't overwrite each other's files. Entries for deleted files get pruned.

Failure

IO errors never crash. A toast says "Could not save mark" and the mark still works for the session. Corrupt JSON loads as empty.

{ "version": 1,
  "files": {
    "/Users/jan/notes/rust.md": {
      "a": { "line": 42, "row": 0, "text": "## Ownership" },
      "t": { "line": 118, "row": 3, "text": "Lifetimes are ..." } } } }

serde_json is already a dependency. BTreeMap keeps the output stable.

  1. handle_event: Ctrl+c is checked first, then pending_key, then is_help_toggle. The second key always belongs to the mark command.
  2. a-z sets or jumps. Any other key, including Esc and A-Z, cancels silently.
  3. Set: anchor_at, insert, store.set, toast Mark 'a' set.
  4. Jump: resolve, push (file_idx, offset) to nav_history, then scroll. An unknown mark shows Mark 'a' not set.
  5. Slide mode: setting uses the top line of the current slide. Jumping selects the slide that contains the resolved line.
  6. Mouse capture moves to M. The help overlay gets a new "Marks" section.

4. Margin marker

Each content row is drawn as │ followed by the content (viewer.rs:2528). On marked rows, the letter replaces the │. The space column stays, so content never touches the letter. Content width doesn't change either, so setting the first mark doesn't reflow the page.

Risks

Stamping per event

A line that gets flushed late, at the next block's Start event, picks up that block's offset. At worst it's off by one block. The round-trip tests will catch it, and the fix goes in the renderer if needed.

~50 Line { .. } literals

Each one needs the new field. This is a mechanical change. A Line::new(spans, meta) constructor keeps it tidy.

Muscle memory

Moving mouse capture to M changes behavior for existing users. Call it out in the README and changelog.
