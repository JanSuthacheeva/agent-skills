    api: invoices: drop currency query parameter
    
    The currency query parameter let clients request totals in a currency
    we never converted to, so the amount was returned with a wrong label.
    The invoice currency now always comes from the owning account.
    
    BREAKING CHANGE: GET /invoices/<id> no longer accepts the currency query
    parameter. Clients must stop sending it and read currency from the
    response instead.
