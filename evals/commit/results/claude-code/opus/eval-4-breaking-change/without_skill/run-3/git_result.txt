    api: invoices: drop currency query parameter
    
    The currency param let clients request totals in a currency that was
    never converted to. Invoices now always use the owning account's
    currency.
    
    BREAKING CHANGE: GET /invoices/<id> no longer accepts the `currency`
    query parameter. Clients must stop sending it and read `currency` from
    the response instead.
    
    Refs: ECOM-88
