    api: drop currency query param from invoice endpoint
    
    GET /invoices/<id> now always returns the invoice in the owning
    account's currency. The currency query parameter let clients request
    totals in a currency that was never actually converted to.
    
    BREAKING CHANGE: the currency query parameter is no longer accepted.
    Clients must stop sending it and read currency from the response.
    
    Refs: ECOM-88
