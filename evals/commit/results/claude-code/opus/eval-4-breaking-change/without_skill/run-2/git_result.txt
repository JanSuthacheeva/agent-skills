    api: invoices: drop currency query parameter
    
    GET /invoices/<id> no longer accepts a `currency` query parameter. The
    currency is now always taken from the invoice's owning account. The
    parameter only relabeled the response and let clients request totals in
    a currency we never converted to.
    
    BREAKING CHANGE: clients sending `currency` must drop it and read
    `currency` from the response instead.
    
    Refs: ECOM-88
